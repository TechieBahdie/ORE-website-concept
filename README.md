# ỌRẸ website concept

A responsive, single-page storefront concept for ỌRẸ | Joggers & Tank Tops.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository and upload `index.html`.
2. In Vercel, import that repository.
3. Framework preset: Other.
4. Build command: leave blank.
5. Output directory: leave blank (or `.` if required).
6. Deploy.

## Before making this a live customer store
Replace the stylised product placeholders with approved product photos. Confirm the catalogue, sizes, colours, prices, stock, delivery details, payment method, and current bulk offer with ỌRẸ. The only prices shown here are the publicly visible figures supplied for the concept: ₦4,500 for the ribbed halter neck top and 10 for ₦35,000 bulk offer; reconfirm before publishing.
